# Phosphor

An old terminal: a black page, phosphor-green text, and amber links, in JetBrains Mono throughout. The light mode is pale green-grey paper with dark green text. It brings a matching code theme, used while the Code theme setting is on "Match page theme".

Fonts: JetBrains Mono, under the SIL Open Font License 1.1 (`OFL.txt`; each family's copyright is at its head).
