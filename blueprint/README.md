# Blueprint

A drafting sheet: a deep blue page, white-blue text, and a cyan accent, in Space Grotesk with Space Mono for code. The light mode is a pale blue paper tint with navy text. It brings a matching code theme, used while the Code theme setting is on "Match page theme".

Fonts: Space Grotesk and Space Mono, under the SIL Open Font License 1.1 (`OFL.txt`; each family's copyright is at its head).
