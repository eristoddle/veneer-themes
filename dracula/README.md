# Dracula

The well-known dark palette: deep indigo with purple, pink, and green. Dark is Dracula. Light mode is Veneer’s adaptation (the official light variant is part of the paid Dracula PRO). It keeps Veneer's fonts and brings a matching code theme, used while the Code theme setting is on "Match page theme".

A port of the Dracula palette (https://draculatheme.com), credited to its authors. Source: https://github.com/dracula/dracula-theme. License: MIT. See `NOTICE`.
