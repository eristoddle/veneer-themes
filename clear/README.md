# Clear

Legibility first: body and muted text reach 7:1 (WCAG AAA) in both modes, in Atkinson Hyperlegible. Light is white and near-black; dark is true charcoal with soft white. A theme cannot set the type size, so the body size is Veneer’s own (raise it in Settings > Appearance if you want it larger). It brings a matching code theme, used while the Code theme setting is on "Match page theme".

Fonts: Atkinson Hyperlegible, under the SIL Open Font License 1.1 (`OFL.txt`; each family's copyright is at its head).
