# Broadsheet

Grey-tan newsprint with dense black type and strong heading contrast, in Newsreader with Old Standard TT headings. The dark mode is charcoal with warm grey text. It brings a matching code theme, used while the Code theme setting is on "Match page theme".

Fonts: Newsreader by The Newsreader Project Authors; Old Standard TT by The Old Standard Project Authors, under the SIL Open Font License 1.1 (`OFL.txt`).
