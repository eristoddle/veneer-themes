# Evergreen

A port of the Everforest palette (named Evergreen here because Typora’s gallery already has an Everforest): a warm, green-grey palette designed to be easy on the eyes, light and dark. It brings a matching code theme, used while the Code theme setting is on "Match page theme".

Palette source: https://github.com/sainnhe/everforest (MIT, Copyright (c) 2019 sainnhe). See `NOTICE`. The page keeps Veneer's fonts.

Adaptations: Veneer maps the palette onto its color tokens; muted and subtle text, the accent, and some code colors are nudged a little toward the text color where the palette's own value falls under the contrast floor (4.5:1 for text and links, 3:1 for subtle text and comments).
