# Letterpress

Heavy cotton paper: a warm grey page, deep red accent, and inked headings in Alegreya small caps, with Alegreya for the body. The dark mode is warm graphite with paper-grey text. It brings a matching code theme, used while the Code theme setting is on "Match page theme".

Fonts: Alegreya and Alegreya SC, under the SIL Open Font License 1.1 (`OFL.txt`; each family's copyright is at its head).
