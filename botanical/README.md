# Botanical

Sage greens and cream, herbarium calm: Spectral for the body and Cormorant Garamond for headings. The dark mode is a forest night with sage text. It brings a matching code theme, used while the Code theme setting is on "Match page theme".

Fonts: Spectral and Cormorant Garamond, under the SIL Open Font License 1.1 (`OFL.txt`; each family's copyright is at its head).
