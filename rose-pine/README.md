# Rosé Pine

All natural pine, faux fur, and a bit of soho vibes: muted rose and iris. Light is Rosé Pine Dawn and dark is Rosé Pine (Main). Dawn’s gold is darkened in code strings for contrast; that is Veneer’s adjustment. It keeps Veneer's fonts and brings a matching code theme, used while the Code theme setting is on "Match page theme".

A port of the Rosé Pine palette (https://rosepinetheme.com), credited to its authors. Source: https://github.com/rose-pine/rose-pine-theme. License: MIT. See `NOTICE`.
