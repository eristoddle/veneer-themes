# Galley

A printed book page: ivory paper, warm black type, a very quiet brown accent, in EB Garamond. The dark mode is deep umber with ivory text. It brings a matching code theme, used while the Code theme setting is on "Match page theme".

Fonts: EB Garamond, under the SIL Open Font License 1.1 (`OFL.txt`; each family's copyright is at its head).
