# Night Owl

A port of Night Owl: Light Owl for light and Night Owl for dark, a palette made for late hours and accessibility. It brings a matching code theme, used while the Code theme setting is on "Match page theme".

Palette source: https://github.com/sdras/night-owl-vscode-theme (MIT, Copyright (c) 2018 Sarah Drasner). See `NOTICE`. The page keeps Veneer's fonts.

Adaptations: Veneer maps the palette onto its color tokens; muted and subtle text, the accent, and some code colors are nudged a little toward the text color where the palette's own value falls under the contrast floor (4.5:1 for text and links, 3:1 for subtle text and comments).
