# Noir

A high-contrast film still: near-black and white with one deep red accent, in Libre Baskerville with Playfair Display headings. The light mode is a white page with black type and the same red. It brings a matching code theme, used while the Code theme setting is on "Match page theme".

Fonts: Libre Baskerville and Playfair Display, under the SIL Open Font License 1.1 (`OFL.txt`; each family's copyright is at its head).

A few text tones were nudged toward the text color to reach the contrast floor (4.5:1 for body text).
