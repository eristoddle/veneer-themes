# Primer

A port of GitHub’s Primer colors, light and dark: neutral greys with a clear blue. It brings a matching code theme, used while the Code theme setting is on "Match page theme".

Palette source: https://github.com/primer/primitives (MIT, Copyright (c) 2018 GitHub Inc.). See `NOTICE`. The page keeps Veneer's fonts.

Adaptations: Veneer maps the palette onto its color tokens; muted and subtle text, the accent, and some code colors are nudged a little toward the text color where the palette's own value falls under the contrast floor (4.5:1 for text and links, 3:1 for subtle text and comments).
