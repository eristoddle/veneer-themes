# Iceberg

A port of Iceberg, a bluish dark-and-light palette easy on the eyes. It brings a matching code theme, used while the Code theme setting is on "Match page theme".

Palette source: https://github.com/cocopon/iceberg.vim (MIT, Copyright (c) 2014 cocopon). See `NOTICE`. The page keeps Veneer's fonts.

Adaptations: Veneer maps the palette onto its color tokens; muted and subtle text, the accent, and some code colors are nudged a little toward the text color where the palette's own value falls under the contrast floor (4.5:1 for text and links, 3:1 for subtle text and comments).
