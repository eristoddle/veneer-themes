# Tokyo Night

A port of Tokyo Night: Day for light and Night for dark, with its blue accent and purple and orange code colors. It brings a matching code theme, used while the Code theme setting is on "Match page theme".

Palette source: https://github.com/enkia/tokyo-night-vscode-theme (Night) and https://github.com/folke/tokyonight.nvim (Day) (MIT, Copyright (c) 2018-present Enkia (Night); Day is from folke/tokyonight.nvim, Apache License 2.0 (https://github.com/folke/tokyonight.nvim/blob/main/LICENSE)). See `NOTICE`. The page keeps Veneer's fonts.

Adaptations: Veneer maps the palette onto its color tokens; muted and subtle text, the accent, and some code colors are nudged a little toward the text color where the palette's own value falls under the contrast floor (4.5:1 for text and links, 3:1 for subtle text and comments).
