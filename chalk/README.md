# Chalk

A slate chalkboard: deep green-grey, chalk-white text, and a soft yellow accent, in Nunito. The light mode is pale slate with charcoal. It brings a matching code theme, used while the Code theme setting is on "Match page theme".

Fonts: Nunito, under the SIL Open Font License 1.1 (`OFL.txt`; each family's copyright is at its head).

A few text tones were nudged toward the text color to reach the contrast floor (4.5:1 for body text).
