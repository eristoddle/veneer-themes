# Studio

A clean modern sans in cool greys with one teal accent, set in IBM Plex Sans with IBM Plex Mono for code. The dark mode is graphite. It brings a matching code theme, used while the Code theme setting is on "Match page theme".

Fonts: IBM Plex Sans by IBM Corp.; IBM Plex Mono by IBM Corp., under the SIL Open Font License 1.1 (`OFL.txt`).
