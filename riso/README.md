# Riso

Risograph print: a cream sheet with the body in deep ink blue, fluorescent pink used sparingly for links, and blue in code, in Work Sans. The dark mode is an ink-blue page with cream text and a pink accent. It brings a matching code theme, used while the Code theme setting is on "Match page theme".

Fonts: Work Sans, under the SIL Open Font License 1.1 (`OFL.txt`; each family's copyright is at its head).
