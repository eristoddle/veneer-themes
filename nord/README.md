# Nord

The arctic palette: cool blue-greys with a frost-blue accent. Dark is Nord (Polar Night and Frost). Light mode is Veneer’s adaptation from the Snow Storm colors. It keeps Veneer's fonts and brings a matching code theme, used while the Code theme setting is on "Match page theme".

A port of the Nord palette (https://www.nordtheme.com), credited to its authors. Source: https://github.com/nordtheme/nord. License: MIT. See `NOTICE`.
