# Catppuccin

Soothing pastels: Latte by day, Mocha by night, with a mauve accent. Light is Catppuccin Latte and dark is Catppuccin Mocha. It keeps Veneer's fonts and brings a matching code theme, used while the Code theme setting is on "Match page theme".

A port of the Catppuccin palette (https://catppuccin.com), credited to its authors. Source: https://github.com/catppuccin/catppuccin. License: MIT. See `NOTICE`.
