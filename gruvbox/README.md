# Gruvbox

Retro groove: warm brown-greys, cream, and orange. Both modes are the official Gruvbox light and dark (medium contrast). It keeps Veneer's fonts and brings a matching code theme, used while the Code theme setting is on "Match page theme".

A port of the Gruvbox palette (https://github.com/morhetz/gruvbox), credited to its authors. Source: https://github.com/morhetz/gruvbox. License: MIT/X11 (as the repository’s README and package.json state). See `NOTICE`.
