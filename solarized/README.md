# Solarized

Ethan Schoonover’s precision palette on warm cream and deep teal. Both modes are the official Solarized Light and Dark. Body text is one step stronger than the official base00 and base0 (base01 and base1) to reach the 4.5:1 contrast floor; this is Veneer’s adjustment. It keeps Veneer's fonts and brings a matching code theme, used while the Code theme setting is on "Match page theme".

A port of the Solarized palette (https://ethanschoonover.com/solarized/), credited to its authors. Source: https://github.com/altercation/solarized. License: MIT. See `NOTICE`.
