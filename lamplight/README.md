# Lamplight

Designed dark-first for night writing with little blue light: an amber-brown page, warm cream text, and an ember accent, in Crimson Pro. The light mode is parchment with brown ink. It brings a matching code theme, used while the Code theme setting is on "Match page theme".

Fonts: Crimson Pro, under the SIL Open Font License 1.1 (`OFL.txt`; each family's copyright is at its head).

A few text tones were nudged toward the text color to reach the contrast floor (4.5:1 for body text).
